For All
Sobre o Projeto

O For All é um aplicativo desenvolvido por alunos do 3º ano “D” da ETEC Antônio de Pádua Cardoso, com o objetivo de conectar pessoas interessadas em realizar doações com instituições e grupos que necessitam desse apoio.
<img width="370" height="610" alt="image" src="https://github.com/user-attachments/assets/73e07b98-5183-4c2d-982f-7f79d81b4152" />


O projeto foi criado utilizando a plataforma Kodular, com foco em simplicidade, acessibilidade e impacto social.

Funcionalidades
Carrinho de doações (os itens não são vendidos, apenas disponibilizados para doação)
Organização de itens por categorias
Busca de itens disponíveis
Alternância entre modo claro e modo escuro
Interface simples e intuitiva
Objetivo

Facilitar a conexão entre doadores e instituições, tornando o processo de doação mais acessível, organizado e eficiente.

Tecnologias Utilizadas
Kodular (desenvolvimento do aplicativo)
Banco de dados integrado à plataforma
Como utilizar o projeto
Baixe o arquivo .aia disponível neste repositório
Acesse o Kodular Creator
Importe o projeto
Execute ou realize alterações conforme necessário
Status do Projeto

Protótipo funcional

O aplicativo atende aos requisitos propostos, com possibilidade de melhorias e expansão futura.

Melhorias Futuras
Implementação de sistema de login
Integração com geolocalização de instituições
Comunicação entre doadores e instituições
Sistema de notificações
Desenvolvedores

Projeto desenvolvido pelos alunos do 3º ano “D” da ETEC Antônio de Pádua Cardoso.
